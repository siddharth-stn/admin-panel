# Theme Colors

Color reference extracted from the SidePanel component for consistent styling across the app.

---

## Day Mode (Light)

| Usage | Tailwind Class | Color |
|-------|---------------|-------|
| **Sidebar background** | `bg-white` | White |
| **Sidebar border** | `border-gray-200` | Light gray border |
| **Text (default)** | `text-gray-900` | Near-black |
| **Text (active link)** | `text-blue-600` | Blue |
| **Background (active link)** | `bg-gray-100` | Very light gray |
| **Background (hover)** | `hover:bg-gray-100` | Very light gray |
| **Brand title** | `text-gray-900` | Near-black |
| **Hamburger text** | `text-gray-500` | Medium gray |
| **Hamburger hover bg** | `hover:bg-gray-100` | Very light gray |
| **Hamburger focus ring** | `focus:ring-gray-200` | Light gray ring |

---

## Night Mode (Dark)

| Usage | Tailwind Class | Color |
|-------|---------------|-------|
| **Sidebar background** | `dark:bg-gray-800` | Dark charcoal |
| **Sidebar border** | `dark:border-gray-700` | Medium-dark gray |
| **Text (default)** | `dark:text-white` | White |
| **Text (active link)** | `dark:text-blue-400` | Light blue |
| **Background (active link)** | `dark:bg-gray-700` | Medium-dark gray |
| **Background (hover)** | `dark:hover:bg-gray-700` | Medium-dark gray |
| **Hamburger text** | `dark:text-gray-400` | Medium gray |
| **Hamburger hover bg** | `dark:hover:bg-gray-700` | Medium-dark gray |
| **Hamburger focus ring** | `dark:focus:ring-gray-600` | Darker gray ring |

---

## Quick Copy-Paste Patterns

**Default text:**
```
text-gray-900 dark:text-white
```

**Active state:**
```
bg-gray-100 text-blue-600 dark:bg-gray-700 dark:text-blue-400
```

**Hover state:**
```
hover:bg-gray-100 dark:hover:bg-gray-700
```

**Border/divider:**
```
border-gray-200 dark:border-gray-700
```

**Container background:**
```
bg-white dark:bg-gray-800
```

**Button (primary):**
```
bg-blue-600 text-white dark:bg-blue-400 dark:text-gray-900
```

**Button hover:**
```
hover:bg-blue-700 dark:hover:bg-blue-500
```

**Link hover:**
```
hover:text-blue-600 dark:hover:text-blue-400
```

**Separator/muted text:**
```
text-gray-400 dark:text-gray-500
```
